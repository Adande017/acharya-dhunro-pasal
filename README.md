# Acharya Dhunro Pasal — Corn Puff Pipes

Premium snack-shop landing page for **Acharya Dhunro Pasal**, featuring **Corn Puff Pipes** (crunchy puffed corn snacks shaped like tiny pipes — snack food, not tobacco).

## Stack

- Vite + React + TypeScript
- Single-page static SPA with CSS scroll-snap + light 3D card tilt
- φ-inspired yellow / gold palette (cream → corn → amber)

## Quick start

```bash
cd greyskull-me
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`).

## Production build

```bash
npm run build
npm run preview   # optional local preview of dist/
```

Output lands in `dist/`. Deploy that folder to any static host.

## Sections

1. Hero — shop name, Corn Puff Pipes, hero photo, Call + Pay CTAs  
2. Product story + photo gallery
